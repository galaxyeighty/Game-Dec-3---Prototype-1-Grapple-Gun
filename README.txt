What went well?

Controlling the character and the grapple math itself was fine, I had no troube getting the actual code done.

What didn't go well?

The difficulties of physics and the lack of granularity with Character Controller meant I couldn't lock the players rotation making it so they constantly rotated and wouldn't behave as I had liked.

What challenges did you face?

The physics were the hardest, as well as the several Mathf and Lerp code that made the grapple gun so tricky to handle.

What can you do differently next time?

using Rigidbody and a Capsule Collider would likely have set me up for success rather than going with Character Controller.
